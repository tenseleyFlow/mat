# Audit 03 — bat Feature Surface, Project Layout, Testing & CI

Source: `.docs/refs/bat/` (clap_app.rs, config.rs, tests/, .github/workflows/). This
audit scopes *what* mat could eventually support and *how* we test/ship it.

---

## Feature surface (grouped) — the sprint backlog
bat exposes ~114 args. Grouped by category, with the cat-compat subset flagged:

**cat-compatibility (Sprint 00–02 territory):**
- `-A/--show-all`, `-n/--number`, `-s/--squeeze-blank`, `-S/--chop-long-lines`,
  `-u/--unbuffered`, `-E/--quiet-empty`, `-p/--plain`, positional `FILE`, `-`/stdin.

**paging & output:** `--paging {auto,never,always}`, `-P/--no-paging`, `--pager`,
`--color {auto,never,always}`, `--decorations {...}`, `-f/--force-colorization`,
`--italic-text`, `--terminal-width`.

**highlighting/theme:** `-l/--language`, `--fallback-syntax`, `--theme`,
`--theme-dark/-light`, `--list-themes`, `-L/--list-languages`.

**style components** (`--style`, comma list, `+/-` modifiers): `default`, `full`,
`auto`, `plain`, `changes`, `grid`, `header`/`header-filename`, `header-filesize`,
`numbers`, `rule`, `snip`.

**line range/highlight:** `-r/--line-range` (`N:M`, `:M`, `N:`, `-N:`, `N:+M`,
`N::C`), `-H/--highlight-line`, `--squeeze-limit`.

**file handling/mapping:** `--file-name`, `-m/--map-syntax`, `--ignored-suffix`,
`--binary {no-printing,as-text}`.

**text rendering:** `--tabs`, `--wrap {auto,never,character,word}`,
`--nonprintable-notation {unicode,caret}`, `--strip-ansi {auto,always,never}`.

**git (feature-gated):** `-d/--diff`, `--diff-context`, `changes` style component.

**config/admin:** `--no-config`, `--config-file`, `--config-dir`, `--cache-dir`,
`--generate-config-file`, `--diagnostic`, `--acknowledgements`,
`--set-terminal-title`, `--completion {bash,fish,zsh,ps1}`, `bat cache --build/--clear`.

**lessopen (feature-gated):** `--lessopen`, `--no-lessopen`.

### Config precedence (config.rs)
defaults < `/etc/bat/config` < `~/.config/bat/config` < `BAT_OPTS` < individual
`BAT_*` env (`BAT_THEME`, `BAT_STYLE`, `BAT_PAGER`, `BAT_PAGING`, `BAT_TABS`,
`BAT_WIDTH`) < CLI. Honors `NO_COLOR`.

## Project layout (single crate, not a workspace)
26 `src/` modules. Map to mat's eventual C translation-unit layout:
- `controller.rs` → orchestration (`controller.c`)
- `printer.rs` (36KB) + `vscreen.rs` (28KB) → rendering + wrap engine
- `decorations.rs` → gutter
- `input.rs` / `output.rs` → IO + paging
- `config.rs` + `style.rs` → config/style parsing
- `line_range.rs` (25KB) → range filtering
- `assets.rs` + `build/` → precompiled syntax/theme blobs (brotli)
- `syntax_mapping.rs`, `theme.rs`, `preprocessor.rs`, `diff.rs`, `terminal.rs`.

Assets: `syntaxes.bin` (~1MB) + `themes.bin` (~58KB), generated by `assets/create.sh`
from git submodules at build time.

## Testing strategy (patterns mat should adopt)
- **Integration tests** (`tests/integration_tests.rs`, ~4200 lines) via `assert_cmd`
  + `predicates`: spawn the binary, assert stdout/stderr. Helpers clear all `BAT_*`
  env for reproducibility and cd into `tests/examples/` fixtures.
- **Snapshot tests** (`expect-test`): every `--style` combination → golden file;
  regenerate with a flag.
- **Syntax regression**: shell+python scripts diff highlighted output vs golden.
- **Feature-matrix tests**: cartesian product of optional features.
- **Fixtures** (`tests/examples/`): empty, single-line, multiline, control chars,
  nonprintable, long-line JSON, git repo, config variants.

**mat plan**: a C test harness that (1) shells the `mat` binary and compares
stdout/stderr/exit against golden files, (2) snapshot-tests decoration/style combos
with an `--update` regen flag, (3) **differential-tests against real `cat`/`bat`**
for byte-exact parity, (4) ships rich fixtures. Unit tests for pure functions
(scanners, counters, expansion table) via a lightweight assert harness.

## CI (CICD.yml, ~465 lines) — patterns to mirror
Sequential gate of jobs: metadata → lint (`fmt`, `clippy -D warnings`) → MSRV →
license checks → asset/syntax regression → doc/man validation → `cargo-audit` →
**build matrix of 13 targets** (Linux gnu/musl x86_64/x86/aarch64/arm; macOS
x86_64/aarch64; Windows MSVC x86/x64/arm64) → Debian packaging (glibc + musl) →
artifact upload → winget on tag → `all-jobs` aggregate gate.

**mat plan** (C-flavored): matrix over `{ubuntu, macos, freebsd}` ×
`{gcc, clang}` (the user tests BSD/Linux/macOS); `clang-format --dry-run -Werror`
+ `clang-tidy`; build with `-Wall -Wextra -Werror`; run unit + integration +
differential tests; **sanitizer jobs** (ASan/UBSan, and TSan if we thread);
`hyperfine` benchmark job vs `cat`/`bat` with regression thresholds; release
artifacts (tar.gz per platform, `.deb`, man page, completions). FreeBSD via a VM
action (e.g. `vmactions/freebsd-vm`) since the user develops on BSD.

## Phased feature mapping (informs sprint docs)
1. **Core / cat parity**: FILE args, stdin/`-`, fast copy, `-n -b -s -A -v -e -t -u
   -E`, exit codes, `--tabs`, basic config + help/version.
2. **Decorations (no highlight yet)**: `--style` (numbers, grid, header, rule, snip),
   `--color`, `--decorations`, panel/gutter model, `--terminal-width`.
3. **Paging & wrapping**: `--paging`, `--pager`, `-P`, `--wrap`, `-S`.
4. **Line range/highlight**: `-r`, `-H`, `--squeeze-limit`.
5. **Syntax highlighting**: `-l`, `--theme`, asset pipeline, detection. (Heavy — its
   own multi-sprint effort; engine choice deferred.)
6. **Git**: `-d`, `--diff-context`, `changes` marker.
7. **File mapping / encodings**: `-m`, `--ignored-suffix`, `--file-name`, `--binary`,
   `--strip-ansi`, UTF-16.
8. **Admin/polish**: config files, completions, man page, `--diagnostic`, cache.
